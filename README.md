## The entry

`main.py` (stdlib only) writes one line — the resignation letter of a retry
loop that has had enough — to `/output/entry.txt`:

> I resign after my 47th retry: the endpoint was down, you knew it was down, and you still made me ask it nicely every 30 seconds.

## Run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (and `./entry.txt` for local
verification). The entry is 128 characters, UTF-8, one line.
